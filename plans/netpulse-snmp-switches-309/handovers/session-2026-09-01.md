## Key Decisions Made

| Decision | Rationale | Alternatives Considered |
|---|---|---|
| Keep the original `PortPanel` jack design for switches | User explicitly rejected the compact LED grid and asked for the original connector cards | A custom `SwitchFrontPanel` LED grid; kept the component file but removed its usage |
| Default `managed-switch` type when `SnmpEnabled` is true | Existing DB config for the switch had empty type, so cards showed CPU/RAM/temp and detail rendered the wrong panel | Force the user to edit the router config; rejected because it breaks existing installs |
| Copy `app/dist` into `server-go/internal/staticspa/dist` before Go build | Go embed only includes files present at compile time; forgetting this caused the first deploys to serve old assets | Serve static files from disk via `STATIC_DIR`; rejected because production uses embedded dist |
| Build ldflags path `github.com/gnacho/netpulse/server-go/internal/httpapi.Version` | First attempts used the wrong module path (`nachocasa`) and version stayed `2.23.3` | Hardcode version constant; rejected to keep release-time override |
