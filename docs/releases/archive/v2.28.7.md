## v2.28.7

### Fixed / Arreglado

- **OpenWrt `.apk` name collision (#573, fix #586)**: the package workflow built the `.apk` under two targets (qualcommax/ipq807x and armsr/armv8) that produce the **same filename** (no arch in the name), so on upload (`--clobber`) only one survived. This release now publishes a **single `aarch64_generic` `.apk`** (armsr/armv8), installable on generic and cortex-a53 aarch64; the cortex-a53 `.ipk` stays for opkg.
  **Colisión de nombre de los `.apk` OpenWrt (#573, fix #586)**: el workflow construía el `.apk` con dos targets que generaban el **mismo nombre** (sin arch), así que en el upload solo sobrevivía uno. Ahora se publica un **único `.apk` `aarch64_generic`**, instalable en aarch64 genérico y cortex-a53; el `.ipk` cortex-a53 se mantiene para opkg.
