## EN

- **Alerts render in your language** ([#671](https://github.com/gnacho/netpulse/issues/671)): titles, descriptions and hints carry their type and values, and the app translates them in the active language — no more mixed Spanish in an English feed.
- **Hostnames survive the browser translator** ([#666](https://github.com/gnacho/netpulse/issues/666)): the page language now follows the UI and network data is marked do-not-translate, so translators stop "correcting" names like crowed-pixeltab.
- **OpenWrt packages for x86/64** ([#672](https://github.com/gnacho/netpulse/issues/672)): agent and on-router server published for x86/64 (.ipk 24.10, .apk 25.12), architecture derived from the SDK.
- Dev dependency bump: js-yaml 4.3.2.

## ES

- **Las alertas en tu idioma** ([#671](https://github.com/gnacho/netpulse/issues/671)): título, descripción y sugerencia llevan su tipo y sus valores, y la app los traduce al idioma activo — adiós al feed mezclado en español con la app en inglés.
- **Los hostnames sobreviven al traductor del navegador** ([#666](https://github.com/gnacho/netpulse/issues/666)): el idioma de la página sigue a la UI y los datos de red se marcan como no traducibles, así el traductor deja de "corregir" nombres como crowed-pixeltab.
- **Paquetes OpenWrt para x86/64** ([#672](https://github.com/gnacho/netpulse/issues/672)): agente y servidor on-router publicados para x86/64 (.ipk 24.10, .apk 25.12), arquitectura derivada del SDK.
- Bump de dependencia de desarrollo: js-yaml 4.3.2.
