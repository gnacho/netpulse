## NetPulse 2.48.1

### Fixed

- Restores LAN access for existing installs that upgrade to 2.48. The HTTP listener no longer binds only to loopback when TLS is not enabled. Existing installs keep listening on all interfaces, fresh installs stay on loopback, and the choice is remembered in `data/.bind-mode`.
- If you upgraded to 2.48.0 and cannot reach the UI, upgrade to 2.48.1. Immediate workaround on 2.48.0: set `NETPULSE_BIND=0.0.0.0` in the service environment and restart.

### Changed

- Refreshed the app and Go module dependencies.
- Pinned GitHub Actions to commit SHAs and verified downloaded CI artifacts.
- Includes agent 3.0.28 binaries.

### Upgrade

Download the `netpulse_2.48.1_linux_amd64.tar.gz` asset for the server, or use your usual install method. The agent binaries are published as `netpulse-agent_2.48.1_linux_*.tar.gz`.

Closes #1647.
