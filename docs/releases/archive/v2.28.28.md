## What's Changed

**Agent versioning decoupled from the server release (#790).** Until now every server release rebuilt the agent with the release tag number, so the whole fleet was flagged as outdated on every release even when the agent code had not changed at all. The agent now has its own version, stored in `agent/VERSION` (starting at 3.0.0), which CI injects into both the agent binary and the server. The fleet updates once to 3.0.0 and from then on only gets an update prompt when the agent code actually changes; the release workflow fails if the agent code changed without a version bump. Updating from older versions jumps straight to this release - database migrations are state-based and idempotent, no step-by-step path needed.

**The rearm button is no longer offered for external agents (#792).** The router detail header showed "Rearm" for any stale agent, including external pushers without SSH (e.g. a beacon-managed switch), which the backend already rejected. The button now hides itself for external kinds everywhere.

## Qué hay de nuevo

**Versionado del agente desacoplado del server (#790).** Hasta ahora, cada release del server rebuildaba el agente con el número del tag y toda la flota se marcaba como desactualizada en cada release aunque el código del agente no hubiera cambiado. El agente pasa a tener versión propia en `agent/VERSION` (arranca en 3.0.0), que el CI inyecta tanto en el binario del agente como en el server. La flota se actualiza una vez a 3.0.0 y, a partir de ahí, solo recibe aviso de actualización cuando el agente cambia de verdad; además, la release falla si el código del agente cambió sin subir la versión. Actualizar desde versiones anteriores salta directo a esta release: las migraciones de la base de datos son por estado e idempotentes, sin pasos intermedios.

**El botón «Rearmar» ya no se ofrece en agentes externos (#792).** La cabecera del detalle de un router mostraba el rearme para cualquier agente caído, incluidos los externos sin SSH (p. ej. un switch gestionado por beacon), que el backend ya rechazaba. Ahora el botón se oculta para tipos externos en todos los sitios.
