# v2.28.8

## English

**Fixed**
- Fleet cards on the "Devices" view no longer label every router as "Main gateway". In live mode the footer fell back to that label because gateway-latency extras only exist in demo. The gateway indicator is now a green pill next to the router name, shown only on the router whose `roleBadge` is Principal (the real gateway), and the whole footer row (label + "View details") was removed because the whole card is already clickable (#593).

**Changed**
- Spanish UI copy moves from "gateway" to "puerta de enlace" (card pill, "Estado de la puerta de enlace", AP backhaul links/latency, AdGuard/reservation/alert captions, Orchestration copy and the via-Internet tooltip). English text unchanged.
