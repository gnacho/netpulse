# NetPulse v2.28.0

**EN:** Scheduled unattended firmware upgrades (#494), wired static-IP hosts discovered via the router ARP table (#507), a bounded poller stop so slow SNMP can no longer hang shutdown (#481), hardened device actions - reserve IP / block device with conflict checks and rollback (#439) - and a full user manual by area and menu, en + es (#418). Note: the 2.26.13/2.26.14 releases were never published (a committed app/node_modules symlink broke goreleaser); their code is consolidated here.

**ES:** Upgrades de firmware programados y desatendidos (#494), descubrimiento de hosts cableados con IP estática vía tabla ARP (#507), apagado acotado para que un SNMP lento ya no cuelgue el servicio (#481), acciones de dispositivo endurecidas - reservar IP / bloquear con detección de conflictos y rollback (#439) - y manual de usuario completo por área y menú, es + en (#418). Nota: las releases 2.26.13/2.26.14 no llegaron a publicarse (un symlink app/node_modules commiteado rompía goreleaser); su código se consolida aquí.
