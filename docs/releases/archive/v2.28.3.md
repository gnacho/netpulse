## v2.28.3

### Added / Añadido

- **Per-client traffic in live mode (#551)**: the device detail now shows real per-client traffic (current, total and a chart for 24h / 7d / 30d ranges) when the router's source reports it. Per router the preferred source is **nlbwmon** (covers wired clients and everything the router routes); when unavailable it falls back to **per-station counters from `ubus hostapd get_clients`** (`bytes.rx/tx`, wifi clients on that AP), which the agent now reports. The per-client bandwidth store (from #337/#357) is wired end to end: delta ingest with rollups that compute real rates (previously left bps at 0), a `GET /api/devices/{mac}/traffic` API and a live per-client rate in the overview. Note: wired clients behind the gateway will not show traffic until its pusher (NetGrip) emits the `clientBw` section; on a router running the NetPulse agent with nlbwmon installed everything is covered.

- **Tráfico por cliente en vivo (#551)**: el detalle de un dispositivo ahora muestra su tráfico real (actual, total y gráfico por rangos 24 h / 7 d / 30 d) cuando la fuente del router lo reporta. Por router la fuente preferente es **nlbwmon** (cubre cableados y todo lo que enruta); si no está disponible se usan los **contadores por estación de `ubus hostapd get_clients`** (`bytes.rx/tx`, clientes wifi asociados a ese AP), que el agente ya reporta. La store de ancho de banda por cliente (del #337/#357) queda cableada de extremo a extremo: ingesta por deltas con rollups que calculan tasas reales (antes dejaban los bps a 0), API `GET /api/devices/{mac}/traffic` y tasa actual por cliente en el overview. Nota: los clientes cableados del gateway no tendrán tráfico hasta que su pusher (NetGrip) emita la sección `clientBw`; en un router con agente NetPulse y nlbwmon instalado queda cubierto todo.

### Changed / Cambiado

- **Channel analysis redesigned LuCI-style (#542, #545, #557)**: one chart per band (2.4 GHz and 5 GHz) so the frequency gap and channel label overlap disappear; X axis with uniform channel slots per band; router selector shows all available (those with scans first) and warns when a router reports no scans (NetGrip); signal noise below -90 dBm is ignored.

- **Análisis de canales rediseñado al estilo LuCI (#542, #545, #557)**: una gráfica por banda (2.4 GHz y 5 GHz) para que el hueco de frecuencia y el solape de etiquetas de canal desaparezcan; eje X con slots de canal uniformes por banda; el selector de router muestra todos los disponibles (primero los que escanean) y avisa cuando uno no reporta escaneos (NetGrip); se ignora el ruido por debajo de -90 dBm.
