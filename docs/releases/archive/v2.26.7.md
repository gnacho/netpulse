## What's new / Novedades

**EN** — Two quality-of-life fixes from the forum feedback wave. The CSP now allows inline styles, so Radix dialogs (command palette included) stop logging a console violation on every open and their enter/exit transitions actually run; script-src remains strictly 'self'. And there is a new in-app Help section with guided walkthroughs for the five flows a first-day admin needs — first login and password, onboarding a router, installing an agent (one-click button first, pairing-token one-liner as the manual fallback), reading the channel plan, and running a firmware upgrade — in Spanish and English, quoting the real UI labels as chips so the help drifts together with the interface instead of going stale.

**ES** — Dos arreglos de calidad de vida de la tanda de feedback del foro. El CSP ahora permite estilos inline, así que los diálogos de Radix (paleta de comandos incluida) dejan de loguear una violación de consola en cada apertura y sus transiciones de entrada/salida por fin se ejecutan; script-src sigue estricto. Y hay una nueva sección de Ayuda dentro de la app con recorridos guiados para los cinco flujos que un admin necesita el primer día — primer arranque y contraseña, alta de un router, instalación del agente (botón de un clic primero y one-liner con token de pairing como alternativa manual), lectura del plan de canales y upgrade de firmware — en español e inglés, citando las etiquetas reales de la UI como chips para que la ayuda derive junto con la interfaz en vez de quedarse vieja.
