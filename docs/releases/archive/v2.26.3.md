## What's new / Novedades

**EN** — The update wizard now shows a real changelog before you apply an update: the list of commits between your version and the latest one (short sha + subject, newest first), how many changes are coming, and a link to the full comparison on GitHub. Works in both rolling (SHA) and stable (tag) modes, caches the result so the daily check does not repeat it, and degrades gracefully: if the comparison cannot be fetched, the wizard falls back to the previous release-notes view.

**ES** — El asistente de actualización ahora muestra un changelog de verdad antes de aplicar: la lista de commits entre tu versión y la última (sha corto + asunto, lo más reciente primero), cuántos cambios entran y un enlace a la comparación completa en GitHub. Funciona tanto en modo rolling (por SHA) como estable (por tag), cachea el resultado para no repetir la consulta en cada chequeo diario y degrada sin romper nada: si el compare no se puede consultar, el asistente vuelve a la vista de notas anterior.
