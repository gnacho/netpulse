## What's new / Novedades

**EN** — The agent now ships for MIPS devices: `mipsle` soft-float (MT7621 and the rest of the little-endian targets, the most common case) and `mips` soft-float (big-endian, ath79 and friends). Available as release tarballs, through the in-app install/reinstall buttons (the server embeds both binaries and serves the right one), and via the one-liner, which now detects the endianness on its own since `uname -m` just says "mips" for both. If you have an MT7621 box that was left out, this release is for it.

**ES** — El agente ya se compila para dispositivos MIPS: `mipsle` soft-float (MT7621 y demás targets little-endian, el caso más común) y `mips` soft-float (big-endian, ath79 y compañía). Disponible como tarballs de release, a través de los botones de instalar/reinstalar de la app (el server embebe ambos binarios y sirve el correcto) y con el instalador de una línea, que ahora detecta el endianness por sí mismo porque `uname -m` dice "mips" para ambos. Si tienes un equipo MT7621 que se quedaba fuera, esta release es para él.
