Two things that failed silently now tell you the truth: Web Push, and the badge of every unit in the fleet.

- Web Push reaches iPhones again, and Settings has a Send test button so you find out your subscription is broken before an urgent alert is missed (#1974, #1973, reported by @mgrupenhoff).
- A unit's role badge follows what the unit proves instead of a config flag, so access points and NAS units stop wearing the switch badge (#1892, @Bann-DEV).
- One corrupt known_hosts line no longer takes SSH down for the whole fleet (#2014, @gnulan).

### Added

- Send test button for push notifications, with the push service answer on screen (#1973).
- The WAN traffic chart draws Curve or Bars, and remembers the choice per browser. The fleet sparkline matches (#1975).
- The client type filter groups speakers as entertainment and servers as computers (#1981).

### Changed

- The UI says unit for an enrolled box and client for a network client, consistently in both locales (#1980).

### Fixed

- Web Push on iOS: the VAPID subject was `mailto:netpulse@localhost` and Apple rejected every push with `403 BadJwtToken` (#1974).
- Removing an agent no longer leaves the unit reporting that the agent is down (#1979).
- `owut check` evaluates the target picked in the UI, and a silent run says so instead of showing nothing (#1977, #1978).
- A unit without a temperature sensor no longer draws a flat 0 C (#1947).
- The manual tagging form has Save and Cancel, and closing it no longer discards the draft silently (#1982).
- A unit card refreshes once an agent install finishes (#1894).
- A deleted client comes back when it returns with an IP (#1984).
- Dragging a node in the topology no longer turns into a pan or opens the tagging panel on touch screens (#1983).
- SSH survives a corrupt known_hosts entry: writes are serialized and the file is replaced atomically, and unreadable lines are dropped with a journal entry instead of being fatal (#2014).
