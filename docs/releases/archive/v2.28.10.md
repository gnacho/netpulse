# v2.28.10

## English

**Fixed**
- The router detail RAM caption always showed "512 MB total" (#590): it was computed from the demo extras resolver (whose fallback for any unknown router is the demo entry with 512 MB), even in live mode. It now uses the real `ramMb` from the backend (`/api/routers/{id}`).

**Added**
- Live performance history on the router detail: the backend already served the real 1h/24h/7d cpu/ram/temp series but the front ignored them and painted the synthetic demo series (always "peaking at 21:00", random walk around the current value). In live mode the three charts now use the real per-router history for the selected range; demo keeps its canonical series. A device without history yet shows a single point with its current value instead of breaking the panel.

## Español

**Corregido**
- El caption de RAM del detalle de router siempre mostraba "512 MB total" (#590): se calculaba con el resolver de extras de demo (cuyo fallback para cualquier router desconocido es la entrada demo con 512 MB), incluso en live. Ahora usa el `ramMb` real del backend (`/api/routers/{id}`).

**Añadido**
- Historia real de rendimiento en el detalle de router: el backend ya servía las series reales 1h/24h/7d de cpu/ram/temp pero el front las ignoraba y pintaba la serie sintética de demo (siempre "picaba a las 21:00", recorrido aleatorio alrededor del valor actual). En live las tres curvas usan ahora la historia real por router y rango; la demo conserva su serie canónica. Un dispositivo sin historia todavía muestra un punto con su valor actual en lugar de romper el panel.
