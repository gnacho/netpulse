## Changed

### Safer firmware upgrades page (#477)

The list only includes OpenWrt/GL.iNet routers with an agent (managed switches and beacon-only devices are gone from the page), the form prefills model and target detected by the agent itself, and starting an upgrade requires confirming the target (current to target version, image URL, sha256 verification, reboot warning). Stale upgrade errors on the card carry a relative timestamp so an old failure no longer reads as a dead agent. Scheduled upgrades tracked separately in #494.

La lista solo incluye routers OpenWrt/GL.iNet con agente (los switches gestionados y los dispositivos solo-beacon desaparecen de la página), el formulario se prefiere con el modelo y target detectados por el propio agente y arrancar un upgrade exige confirmar el objetivo (versión actual a objetivo, URL de la imagen, verificación sha256 y aviso de reinicio). Los errores de upgrade antiguos de la tarjeta llevan marca de tiempo relativa para que un fallo viejo no se lea como agente caído. Las actualizaciones programadas quedan como seguimiento en #494.
