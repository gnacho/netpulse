## EN

**Wired clients behind non-standard bridge ports are now discovered (#506).** The agent filtered bridge FDB MACs through a hardcoded port-name allowlist; physical ports with unusual names (the BPI-R4 SFP cages are named `sfp-lan`/`sfp-wan` on OpenWrt 25.12+) were silently dropped, so static-IP hosts behind them (e.g. behind an unmanaged switch, no DHCP lease) never showed up as clients. The filter is now a denylist (wireless and virtual interfaces excluded). Also fixed: the `bridge fdb show` path no longer leaks local entries, which could make the server discard all wired clients of a port. Embedded agents now report 2.26.10, so every older fleet agent gets offered the update.

## ES

**Los clientes cableados tras puertos con nombres no estándar ya se descubren (#506).** El agente filtraba las MACs del FDB del bridge con una lista cerrada de nombres de puerto; los puertos físicos con nombres inusuales (las jaulas SFP del BPI-R4 se llaman `sfp-lan`/`sfp-wan` en OpenWrt 25.12+) se descartaban en silencio, y los hosts con IP estática tras ellos (p. ej. detrás de un switch no gestionado, sin lease DHCP) nunca aparecían como clientes. El filtro pasa a ser una lista de exclusión (fuera wireless e interfaces virtuales). También corregido: la vía `bridge fdb show` ya no deja pasar entradas locales, que podían hacer que el servidor descartase todos los clientes cableados de un puerto. Los agentes embebidos ahora reportan 2.26.10, así que a toda la flota anterior se le ofrece la actualización.
