## English

**RouterOS (MikroTik) support, first class** (#969, thanks @samex). New fleet router type polled server-side via the native REST API of RouterOS 7+ (real CPU/RAM/uptime vitals, WAN metrics, package update check), with a hand-rolled binary API client (port 8728) for installs that keep the web interface closed: zero new dependencies, modern login, read-only sentences. The password stays server-side and is never serialized back, factory self-signed TLS is opt-in, and an optional routeros-pusher agent covers api-only units.

**M-Lab NDT is now the default speedtest** (#1037, suggested by @crowedavid). A neutral, non-profit measurement network with an open data policy: a better privacy story than Ookla or Cloudflare. Installs with a saved provider keep it, and a new "auto" schedule runs the test at the quietest hour according to your own traffic history (#1066).

**Topology:**
- Fleet uplinks anchor to their real parent from switch FDB evidence, with the port label (#1047, #1051).
- When the evidence port has an inferred or managed switch circle, the uplink hangs from the circle: gateway to (switch) to AP (#1060).
- The WAN upstream device (ISP modem/ONT) is drawn under the Internet node when its IP matches the WAN gateway (#1042).
- LLDP matching tolerates hostname vs FQDN (#1041); the Proxmox integration absorbs spurious inferred switches (#1053).
- No more hover previews while editing the layout (#1045); the links table agrees with the map (#1063).

**Fixes from your reports** (thanks @crowedavid and @gnulan):
- Roaming feed shows Connect events on wpad-mbedtls APs (#1038).
- Blank screen when switching report ranges fixed (#1029); hourly and daily granularity (#1032, #1033).
- Fleet edit card: changing the type no longer saves and closes; visible labels; firmware target only for OpenWrt/GL.iNet (#1026).
- "Mark all as read" no longer clears the log: separate clear-log button with confirmation and a retention setting (#1034).
- Proxmox: duplicate or empty instance ids are refused (#1057); the detect button is back (#967).
- Traffic history port selector becomes a dropdown with an All/Active/Inactive filter (#1035).
- Port cards: no more hardcoded Spanish strings leaking into other languages; guessed peers carry a network icon (#1039, #1040).
- Alerts are composed in English natively and translated to your language (#1014); release notes show in the client language (#1011).
- Full dependency refresh (#1020, #1022, #1028).
- Dialog polish: close on save, hints collapsed, no uninvited tooltips, focus ring off the close button and on hover (#1064 to #1066, #1068, #1069).

Huge thanks to @crowedavid, whose sharp issue reports shaped most of this release; to @samex for the RouterOS integration; and to @gnulan, @borky and everyone else reporting bugs and discussing ideas. This is what open source is about.

## Español

**Soporte RouterOS (MikroTik) de primera clase** (#969, gracias @samex). Nuevo tipo de router en la flota, sondeado desde el servidor por la API REST nativa de RouterOS 7+ (vitals reales de CPU/RAM/uptime, métricas WAN, comprobación de actualizaciones), con cliente del API binario (puerto 8728) escrito a mano para instalaciones con la interfaz web cerrada: cero dependencias nuevas, login moderno y sentencias de solo lectura. La contraseña solo vive en el servidor y nunca se serializa de vuelta, el TLS autofirmado de fábrica es opt-in, y un agente routeros-pusher opcional cubre unidades solo-api.

**M-Lab NDT es ahora el speedtest por defecto** (#1037, idea de @crowedavid). Una red de medición neutra y sin ánimo de lucro, con política de datos abierta: mejor privacidad que Ookla o Cloudflare. Las instalaciones con proveedor guardado lo conservan, y un nuevo modo "auto" ejecuta el test a la hora de menos tráfico según el histórico propio de la red (#1066).

**Topología:**
- Los uplinks de la flota se anclan a su padre real según el FDB de los switches, con etiqueta de puerto (#1047, #1051).
- Si el puerto de la evidencia tiene un círculo de switch (inferido o gestionado), el uplink cuelga del círculo: gateway a (switch) a AP (#1060).
- El equipo aguas arriba del gateway (módem/ONT del ISP) se dibuja bajo el nodo Internet cuando su IP coincide con la puerta de enlace WAN (#1042).
- El matching LLDP tolera hostname vs FQDN (#1041); la integración Proxmox absorbe switches inferidos espurios (#1053).
- Sin previsualizaciones al editar el layout (#1045); la tabla de enlaces coincide con el mapa (#1063).

**Arreglos de vuestros reportes** (gracias @crowedavid y @gnulan):
- El feed de roaming muestra eventos Connect en APs con wpad-mbedtls (#1038).
- Arreglada la pantalla en blanco al cambiar de rango (#1029); granularidad horaria y diaria (#1032, #1033).
- Tarjeta de edición de flota: cambiar el tipo ya no guarda y cierra sola; etiquetas visibles; firmware target solo para OpenWrt/GL.iNet (#1026).
- "Marcar todo como leído" ya no vacía el registro: botón aparte de vaciar registro con confirmación y retención configurable (#1034).
- Proxmox: se rechazan ids de instancia vacíos o duplicados (#1057); el botón detectar está de vuelta (#967).
- El selector de puertos del historial de tráfico es ahora un desplegable con filtro All/Active/Inactive (#1035).
- Tarjetas de puertos: se acabaron los textos en español filtrándose a otros idiomas; los pares inferidos llevan icono de red (#1039, #1040).
- Las alertas se componen en inglés y se traducen a tu idioma (#1014); las notas de release se muestran en el idioma del cliente (#1011).
- Actualización completa de dependencias (#1020, #1022, #1028).
- Pulido de diálogos: cerrar al guardar, hints plegados, tooltips que no saltan solos, foco fuera de la (x) y anillo al pasar el ratón (#1064 a #1066, #1068, #1069).

Enormes gracias a @crowedavid, cuyos reportes afilados formaron la mayor parte de esta release; a @samex por la integración RouterOS; y a @gnulan, @borky y todos los que reportan bugs y discuten ideas. De esto va el open source.
