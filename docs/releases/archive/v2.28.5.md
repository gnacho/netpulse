## v2.28.5

### Fixed / Arreglado

- **Agent copy-command was not runnable (#571)**: the app generated the install one-liner with space-separated options (`--binary /tmp/netpulse-agent ...`), but the installer only parsed `--opt=value`, so it aborted on the first option with `opción desconocida: --binary` and never reached SSH. The installer now accepts both `--opt value` and `--opt=value`.

  **El "copy command" para instalar un agente no era ejecutable (#571)**: la app generaba el one-liner con opciones separadas por espacio, pero el instalador solo aceptaba `--opt=value`, así que abortaba en la primera opción con `opción desconocida: --binary` y no llegaba al SSH. El instalador ahora acepta ambas formas.

- **Installer did not use the server SSH key (#572)**: `install-agent.sh` ran `ssh root@IP` without an explicit identity; when the router only authorized the key NetPulse generates (shown in Settings), SSH failed even though `ssh -i <key> root@IP` worked. The installer now accepts `--ssh-key <path>`, forwards it with `-i` to every ssh/scp call, and the copy-command includes it automatically.

  **El instalador no usaba la llave SSH del servidor (#572)**: `install-agent.sh` hacía `ssh root@IP` sin identidad explícita; si el router solo autorizaba la llave que genera NetPulse (la que muestra Ajustes), el SSH fallaba aunque `ssh -i <llave> root@IP` funcionara. Ahora se acepta `--ssh-key <ruta>`, se reenvía con `-i` a todos los `ssh`/`scp`, y el copy-command la incluye automáticamente.
