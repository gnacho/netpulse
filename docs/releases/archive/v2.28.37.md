## What's new

**Fixes**

- **Agent reinstall no longer wipes your config (#851)**: the console reinstall and the hot token rotation rewrote `/etc/netpulse-agent.env` from scratch and lost hand-added settings like `NETPULSE_SCAN_INTERVAL=0`. Both now preserve any option they don't manage, and the generated env documents the available options as commented defaults.
- **Watchdog cron removed from new installs (#851)**: a blind restart every 2 minutes doesn't fix a crash loop, it just spams the log; the server's dead-man detection plus alerts is what surfaces the problem. procd respawn still covers one-shot crashes, the init restores the binary after sysupgrade, and upgrading cleans the old cron entry and watchdog file.
- **Stale watchdog cron entry self-heals after sysupgrade (#879)**: `/etc` survives but the binary doesn't, so cron logged a missing-command error every 2 minutes. The agent init now removes the orphaned entry at start.
- **Alert actions existed only on hover (#862)**: on phones and tablets they were unreachable. Touch devices now show them always, with their label on its own line so the title keeps its width.
- **CI injected the agent tag as the server version (#869)**: dev builds reported `agent/vX.Y.Z`; only release tags are considered now.

**Added**

- **Per-switch console polling toggle (#863)**: the RTLPlayground firmware console allows a single session and every poll kicked whoever was using the web UI. You can now disable polling per switch (Settings > Routers); with beacon v1.3+ firmware, uptime, MAC and firmware still arrive over UDP.
- **Per-channel notification verbosity (#874)**: each channel (ntfy today, same switch for Telegram, webhook and Web Push) decides whether it receives urgent alerts only (default, unchanged) or everything that passes the feed filter.
- **Notification channels documented (#871)**: the ntfy and Telegram cards and the README now state that channels carry urgent alerts only, separate from the feed level.

## Novedades

**Correcciones**

- **Reinstalar el agente ya no pisa tu configuración (#851)**: el reinstall de la consola y la rotación de token reescribían el env desde cero y perdían ajustos añadidos a mano. Ahora conservan lo que no gestionan y el env documenta las opciones disponibles.
- **Watchdog cron fuera de la instalación (#851)**: un reinicio a ciegas no arregla un bucle de crash; la detección real es la del servidor. El respawn de procd cubre crashes puntuales y el init restaura el binario tras sysupgrade.
- **La entrada de cron del watchdog huérfana se auto-repara tras sysupgrade (#879)**: el init del agente retira la entrada al arrancar si el watchdog ya no existe.
- **Las acciones de alertas solo existían con hover (#862)**: en táctil se muestran siempre, con etiqueta en su propia línea.
- **El CI inyectaba el tag del agente como versión del servidor (#869)**: ahora solo se consideran tags de release.

**Añadido**

- **Toggle "Sondeo por consola" por switch (#863)**: la consola del firmware RTLPlayground admite una sola sesión y cada sondeo echaba a quien estuviera dentro. Desactívalo por switch; con el beacon v1.3+ los datos llegan por UDP.
- **Verbosidad por canal de notificación (#874)**: cada canal decide entre solo urgentes (por defecto) o todo lo que pasa el filtro del feed.
- **Canales de notificación documentados (#871)**: tarjetas de ntfy/Telegram y README explican que los canales solo llevan alertas urgentes.
