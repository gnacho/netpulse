## Added

### Apply the recommended channel from the channel plan page (#500)

The agent now reports each radio's UCI section and the plan page becomes actionable: per-radio Apply button with confirmation (current to target channel, network restart warning), live progress and result feedback, and a one-click revert to the previous channel in the same session. Plans go through the existing plan engine (explicit diff) via the NetGrip executor or agent SSE. Full ES/EN translation of the page and current/best score per radio for context.

El agente ahora reporta la sección UCI de cada radio y la página del plan pasa a ser accionable: botón de aplicar por radio con confirmación (canal actual a objetivo y aviso del reinicio de red), progreso y resultado en vivo, y vuelta al canal anterior con un clic en la misma sesión. Los planes van por el motor existente (diff explícito) vía executor de NetGrip o SSE al agente. Traducción completa ES/EN de la página y puntuación actual/mejor por radio como contexto.

## Fixed

- POST /api/plans with an explicit diff returned 201 with an empty body (empty desired from the DB failed to encode, silently swallowed); JSON clients got EOF.
- The apply-result report died when the ops restarted the router's own network, leaving plans stuck in applying; the agent now retries with backoff for several minutes.

- POST /api/plans con diff explícito devolvía 201 con body vacío (el desired vacío de la BD fallaba al codificar y el error se silenciaba); los clientes JSON recibían EOF.
- El reporte del apply moría cuando las ops reiniciaban la red del propio router, dejando planes en applying eterno; el agente ahora reintenta con backoff durante varios minutos.
