## v2.28.6

### Fixed / Arreglado

- **Installers did not parse the release tag (#564)**: `install.sh`, `install-agent.sh` and `install-collector.sh` resolved `releases/latest` with a positional `cut`, so when GitHub returns a minified single-line payload the version became the release URL and the download broke. They now extract `tag_name` by name, and the installer prints its own version.
  **Los instaladores no parseaban el tag (#564)**: resolvían `releases/latest` con un corte posicional; con la respuesta minificada el tag salía como la URL de la release y la descarga fallaba. Ahora extraen `tag_name` por nombre e informan de su versión.
- **dnsmasq lease file in non-standard locations (#568)**: now resolved via UCI (`dhcp.@dnsmasq[0].leasefile`) with fallback, so hostnames show on routers with a custom lease path. Applies to the agent and the SSH poller.
  **Fichero de leases de dnsmasq en ubicación no estándar (#568)**: ahora se resuelve vía UCI con fallback, así que los hostnames aparecen aunque el leasefile esté en una ruta custom.
- **SSH host-key mismatch locked the gateway (#567)**: the discovery probe (system ssh) and the Go pool negotiate a different host key and share `known_hosts`; on a known but different key the pool now re-onboards with a warning (accept-new with refresh) instead of rejecting.
  **Mismatch de host-key bloqueaba el gateway (#567)**: el pool ahora re-onboarda con aviso en lugar de rechazar.
- **Hardcoded timezone and fake 'firmware up to date' (#566)**: the router info no longer shows `Europe/Madrid` or an 'up to date' pill before real data; unknown values stay empty.
  **Timezone hardcodeado y firmware 'actualizado' falso (#566)**: ya no se muestra `Europe/Madrid` ni una pill 'actualizado' sin datos reales.

### Added / Añadido

- **Generic aarch64 apk (#573)**: the agent and server now publish an `aarch64_generic` apk (armsr/armv8), installable on generic and cortex-a53 routers; `apk add` no longer fails with `uninstallable arch` on non-cortex-a53 platforms.
  **Apk aarch64 genérico (#573)**: se publica un apk `aarch64_generic` instalable en genérico y cortex-a53.
- **Honest native vs NetGrip install choice (#570)**: the agents section explains both options (description, NetGrip port 8090, recommendation) for OpenWrt routers without an agent. NetPulse does not install NetGrip.
  **Elección honesta agente vs NetGrip (#570)**: la sección de agentes explica ambas opciones con el puerto 8090.
- **Honest 'no per-client traffic' message (#574)**: the device detail notes wired clients need nlbwmon (WiFi uses hostapd), and the nlbwmon RAM caveat is documented.
  **Mensaje honesto de 'sin tráfico por cliente' (#574)**: se documenta el caveat de nlbwmon y la fuente por cliente.
