## What's new / Novedades

**EN**

Reliability of agent monitoring and fleet alerts:
- Agent-only routers no longer flap offline on every client roam: the registry retains the agent identity across wireless-only event pushes (#852).
- Agent-down on agent-only routers is now an urgent router alert, so it passes urgent-only notification filters (#850).
- One offline alert per outage: no re-emits while flapping, clean removal from the feed on stable recovery, survives restarts (#846).
- Fresh agent installs against an HTTPS server work out of the box: the installer derives the SPKI fingerprint from the certificate itself (#851).

UI and ports:
- The contracted WAN speed now shows on the topology link (#849).
- 2.5 GbE links display as "2.5 Gbps" and internal DSA conduits no longer appear as fake ports (#847). Agent-side: requires the updated agent (3.0.1) on the routers.
- Custom device icons are honored on the topology map chips (#845).
- Fleet table matches agents by slug or routerId (#848).

Landing:
- One crawlable route per language (10 languages x 3 pages) with proper lang, canonical, hreflang and og:locale; the sitemap lists all 30 URLs (#842).
- Native review pass of the ar, hi, zh and ja translations (#841).
- README documents the anonymous instance counter and its opt-out (#822).

**ES**

Fiabilidad del monitoreo por agente y de las alertas de flota:
- Los routers solo-agente ya no flapean offline con cada roam: el registry conserva la identidad del agente entre pushes de eventos wireless (#852).
- La caida del agente en routers solo-agente ahora es alerta urgente de router y pasa los filtros de notificacion (#850).
- Una alerta offline por caida: sin re-emisiones durante el flapping, se retira del feed al recuperarse de forma estable y sobrevive a reinicios (#846).
- Instalaciones de agente contra un servidor HTTPS funcionan solas: el instalador deriva el fingerprint SPKI del propio certificado (#851).

Interfaz y puertos:
- La velocidad WAN contratada se ve ya en el enlace de la topologia (#849).
- Los enlaces de 2.5 GbE se muestran como "2.5 Gbps" y los conduits DSA internos dejan de aparecer como bocas falsas (#847). En el router hace falta el agente actualizado (3.0.1).
- El icono personalizado de un cliente se respeta en los chips de la topologia (#845).
- La tabla de flota empareja agentes por slug o routerId (#848).

Landing:
- Una ruta indexable por idioma (10 idiomas x 3 paginas) con lang, canonical, hreflang y og:locale correctos; el sitemap lista las 30 URLs (#842).
- Repaso nativo de las traducciones ar, hi, zh y ja (#841).
- El README documenta el contador anonimo de instancias y su opt-out (#822).
