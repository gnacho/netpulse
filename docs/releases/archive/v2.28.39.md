## What's Changed

### Fixed

- **Could not select °F in Settings (#898)** - the unit was saved with quotes and never matched on read.
- **European decimal notation in the WAN totals (#899)** - "TOTAL 24H" and "TOTAL TODAY" now follow your locale: the server sends raw bytes, the client formats like every other rate.
- **Signal matrix legend did not match the real thresholds (#905)** - reworded without relational operators on negative values.
- **DAWN filter option on usteer-only networks (#909)** - only shown when the network actually has DAWN routers.
- **Connect events never appeared (#908)** - the logread parser missed the most common hostapd line format (iface listed once); all observed variants parse now.
- **Push notifications showed a static 16:00:00 time (#914)** - the notifier received events with timestamp 0 (epoch in your timezone); fixed at the source with a regression test.
- **"Agent outdated" alert re-fired every 30 s (#910)** - it was re-sent on every agent push and refreshed its timestamp; now it fires once per actual version change, like the agent-down alert.
- **Initial installer password had ambiguous characters (#895)** - no more 0/O or 1/l/I; same entropy (~94 bits).

### Added

- **Server-wide Weak signal threshold (#904)** - the Settings slider now lives on the server and drives the weak-signal alert for every client.
- **Matrix "Weak signal only" filter uses that threshold (#906)** with an unambiguous label ("weaker than X dBm").
- **Configurable roaming events ingest interval (#907)** - Settings > Data & thresholds; applies without restart, and the events table header shows your real retention and interval.
- **"Unread only" toggle on the Overview alerts card (#916)** - keeps the view clean in normal operation.

Thanks to @crowedavid for the relentless, top-quality reports behind most of this release.

## Novedades

### Arreglado

- **No se podía seleccionar °F en Ajustes (#898)** - la unidad se guardaba con comillas y la lectura nunca coincidía.
- **Notación decimal europea en los totales WAN (#899)** - "TOTAL 24H" y "TOTAL TODAY" siguen tu locale: el servidor manda bytes crudos y el cliente formatea como el resto de tasas.
- **La leyenda de la matriz de señal no coincidía con los umbrales reales (#905)** - reescrita sin operadores sobre valores negativos.
- **Filtro DAWN en redes solo-usteer (#909)** - solo aparece cuando la red tiene routers con DAWN.
- **Los eventos de conexión no aparecían (#908)** - el parser no aceptaba el formato de hostapd más común (iface una sola vez); ahora cubre todas las variantes observadas.
- **Los pushes mostraban una hora estática (16:00:00) (#914)** - el notifier recibía el evento con timestamp 0 (epoch en tu zona); arreglado en origen con test de regresión.
- **La alerta "Agente desactualizado" se repetía cada 30 s (#910)** - se reenviaba con cada push y refrescaba su timestamp; ahora dispara una vez por cambio de versión real.
- **La contraseña inicial tenía caracteres ambiguos (#895)** - sin 0/O ni 1/l/I; misma entropía (~94 bits).

### Nuevo

- **Umbral "Weak signal" server-wide (#904)** - el slider de Ajustes vive ahora en el servidor y alimenta la alerta de señal débil para todos los clientes.
- **El filtro "Solo señal débil" de la matriz usa ese umbral (#906)** con rótulo inequívoco ("peor que X dBm").
- **Intervalo de ingesta de eventos de roaming configurable (#907)** - Ajustes > Datos y umbrales; sin reinicio, y la cabecera de la tabla muestra tus valores reales.
- **Toggle "Solo no leídas" en la tarjeta de Alertas del Overview (#916)** - vista limpia en operación normal.

Gracias a @crowedavid por los informes impecables detrás de casi todo este release.
