## What's new

**Fixes**

- **Agent reinstall over HTTPS (#851)**: the console reinstall (manual and the supervisor's auto-reinstall) generated `/etc/netpulse-agent.env` without `NETPULSE_SERVER_FP`, so the agent kept crash-looping on the SPKI pinning check even with a valid TLS certificate. The server now derives the SPKI pin itself (TLS handshake against its own public URL, cached) and the generated env carries it; the hot token rotation preserves it instead of dropping it.
- **Alert actions easier to see (#862)**: feed row actions are larger (bigger icon, more generous hit area) and show their text label on hover; the Home summary reduces each alert to its title with the same actions, and "Update agent" now goes to the fleet's agent section.
- **Custom device icon missing in the Connected Clients table (#864)**: the table used the deduced type and ignored `iconOverride`; it now follows the same rule as the rest of the panel.

**Added**

- **Firmware, uptime and MAC via beacon (#865)**: the RTLPlayground firmware status datagram now carries firmware version, uptime and switch CPU MAC, and NetPulse ingests them as the primary source (with console fallback), so the panel shows them even with console polling disabled.

## Novedades

**Correcciones**

- **Reinstalar agente desde la consola con servidor HTTPS (#851)**: el script de reinstall (manual y el auto-reinstall del supervisor) generaba el `/etc/netpulse-agent.env` sin `NETPULSE_SERVER_FP` y el agente seguía cayendo en el bucle fatal de pinning aunque el TLS fuera válido. El servidor deriva ahora el pin SPKI por sí mismo (handshake TLS contra su propia URL pública, con caché) y el env generado lo lleva; la rotación de token en caliente también lo conserva.
- **Acciones de alertas más visibles (#862)**: las acciones por fila del feed crecen (icono mayor y área de clic más generosa) y muestran su etiqueta al pasar el cursor; el resumen de Inicio reduce cada alerta al título con las mismas acciones, y "Actualizar agente" navega a la sección de agentes de la flota.
- **El icono personalizado de un cliente no se veía en la tabla de Clientes (#864)**: la tabla usaba el tipo deducido e ignoraba `iconOverride`; ahora sigue el mismo criterio que el resto del panel.

**Añadido**

- **Firmware, uptime y MAC por beacon (#865)**: el datagrama de estado del firmware RTLPlayground lleva ahora versión de firmware, uptime y MAC de la CPU, y NetPulse los ingiere como fuente principal (con fallback a consola), así que el panel los muestra aunque el sondeo por consola esté deshabilitado.
