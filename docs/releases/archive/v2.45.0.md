## Firmware upgrades, your way

Every unit now picks how it updates: **owut (ASU)**, an image **URL**, or a **local upload** of an image you built elsewhere (the server stores it, computes the sha256 and flashes it verified). The owut flow gains explicit steps - *check* to review what would change, *download* to build and fetch the image to the router without flashing, *install* to flash the downloaded one - while the classic "Upgrade now" stays for those who want it in one go. And the config backup no longer dies in the router's /tmp: the agent (3.0.18) uploads it to the server before flashing, the last five per unit are kept, and you can download them right from the unit's card. (#1414)

## Alert levels are notification policy now

Setting a category to "Urgent only" used to make everything else vanish from the log. From this release everything is always recorded in the log and the feed; the level only decides what notifies - use the feed's category filters to hide things visually. On top of that, the firmware alert becomes one episode per unit instead of re-firing every 5 minutes, version strings are compared as versions, and a target older than the installed release gets its own possible-downgrade alert. (#1413, #1411, #1412)

### Also in this release

- Per-subscriber push language: each push subscription remembers your UI language and the notification is composed in it; subscriptions are user-owned, so unsubscribing only removes your own. (#1334)
- Agent matching with physical criteria: when identical bridged APs share a hostname, the bridge MAC decides; an ambiguous hostname no longer invents an association. (#1334)
- Topology renders **all** switch-classified routers, not just the first three, and edge units fan their clients toward the center of the canvas. (#1422, #1416)
- SSID impostor: your own fleet no longer reports itself - units whose agent doesn't report own BSSIDs are recognized by their fleet MAC and derived radios. (#1402)
- Firmware manual brought up to date with the actual page. (#1415)
