## EN

**Honest update checks** (#743): when the check cannot reach GitHub (anonymous API rate limit, network hiccup), the button used to show the last known state as "You're on the latest version". It now says "Could not check right now (reason); try again in a few minutes" instead of lying.

**Documentation honesty** (#751, #752): the project grew from watching into also writing (DHCP reservations, device blocks, orchestration, firmware upgrades), so every blanket "read-only" claim in the READMEs, website, manuals and app strings was replaced with the accurate split: polling is read-only; anything that writes is explicit, admin-triggered, and covered by a snapshot with automatic rollback. English UI now consistently says "Firmware upgrades".

**Dry-run command preview** (#754): reserving an IP or blocking a device no longer applies directly. The server first returns the exact commands that would run on the router (and the rollback commands), the device sheet shows them, and nothing is executed until you press "Run and apply".

**External announcements channel**: the server fetches announcements.json from the repository and the UI renders community-wide notices in the same style as the update ribbon, with a large 22/18 px type, optional link and a persistent per-user dismiss. First notice: the NetGrip beta tester program is open.

As usual, the built-in updater offers this release and applies it with an atomic swap and automatic rollback if the service does not come back.

## ES

**Comprobación de actualizaciones honesta** (#743): si el check no llega a GitHub (límite de la API anónima, red), el botón devolvía el último estado conocido como "estás en la última versión". Ahora dice "No se pudo comprobar ahora (motivo); reintenta en unos minutos" en lugar de mentir.

**Honestidad documental** (#751, #752): el proyecto pasó de mirar a también escribir (reservas DHCP, bloqueos, orquestación, firmware), así que todo claim genérico de "solo lectura" en READMEs, web, manuales y textos de la app se sustituye por el matiz correcto: el sondeo es de solo lectura; lo que escribe es explícito, lo lanza un admin y va con snapshot y rollback. El UI en inglés unifica "Firmware upgrades".

**Previsualización de comandos (dry-run)** (#754): reservar una IP o bloquear un dispositivo ya no aplica directo. El servidor devuelve primero los comandos exactos que se ejecutarían en el router (y los de rollback), la ficha los muestra, y no se ejecuta nada hasta pulsar "Ejecutar y aplicar".

**Canal de avisos externos**: el servidor consulta announcements.json del repositorio y la UI pinta avisos para toda la comunidad con el estilo del ribbon de actualizar, en cuerpo grande 22/18 px, enlace opcional y descarte persistente por usuario. Primer aviso: el programa de beta testers de NetGrip está abierto.

Como siempre, el actualizador integrado ofrece esta release y la aplica con swap atómico y rollback automático si el servicio no vuelve.
