- **Asesor de re-anchor WiFi (#403)**: nuevo panel "Reanclar" en `/roaming` que sugiere mover clientes WiFi a un AP con mejor señal. Soporta usteer (preferido) y DAWN como fallback.

- `server-go/internal/adapters/reanchor.go`: motor de recomendaciones con `ubus call usteer get_clients` (hearing map).
- `server-go/internal/httpapi/reanchor.go`: endpoints `/api/wifi-reanchor/recommendations` y `/api/wifi-reanchor/{mac}/move`.
- `app/src/pages/ReanchorPanel.tsx`: UI de recomendaciones y acción manual.
- Tests unitarios y bump de versión a 2.24.0.
