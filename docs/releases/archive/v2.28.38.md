## What's Changed

### Fixed

- **"Mark all as read" did not stick (#891)** — a snapshot taken before the request reached the server could bounce alerts back to unread until the next cycle. The read state is now re-applied once the operation confirms, and SSE alert events are deduplicated by ID.
- **Push notifications were always sent in Spanish (#888)** — alerts are composed in Spanish and the web UI translates them per user, but ntfy, Telegram and webhook published the raw text. They are now translated server-side at publish time using the same app catalogs.
- **"Agent down - reinstall" banner right after a server restart (#887)** — for the first 90 s after startup, router cards now show a neutral "Waiting for agents to reconnect…" banner; the drastic banner is reserved for persistent failures.
- **Agent env parser kept inline comments (#883)** — `NETPULSE_SCAN_INTERVAL=0     # note` was read as the literal value and fell back to the 30 m default instead of disabling the scan. Agent 3.0.3.
- **Updates failed on installs without a local git clone (#897)** — in the stable layout the update died at the fetch step; the main SHA is now resolved via `git ls-remote`.

### Added

- **Server-wide notification language (#889)** — new `alerts.lang` setting (Settings > Notifications, default English) for ntfy, Telegram and webhook alerts, independent of each client's UI language.
- **Agent recovery logging (#890)** — the whole automatic recovery flow (TTL expiry, SSH restart, push wait, token rotation, reinstall escalation, cooldowns) is now logged with `supervisor:` / `rearmer:` prefixes, and the full strategy is documented in `docs/AGENTE-OPENWRT.md`.

**Full changelog**: [CHANGELOG.md](https://github.com/gnacho/netpulse/blob/main/CHANGELOG.md)

## Novedades

### Arreglado

- **"Marcar todo como leído" no persistía (#891)** — un snapshot tomado antes de que la petición llegara al servidor devolvía las alertas a no leído. Ahora el estado se re-aplica al confirmarse y los eventos SSE se deduplican por ID.
- **Los pushes salían siempre en español (#888)** — las alertas se componen en español y la web las traduce por usuario, pero ntfy, Telegram y webhook publicaban el texto en crudo. Ahora se traducen en el servidor al publicar.
- **Banner de "agente caído" tras un reinicio (#887)** — durante los primeros 90 s tras el arranque se muestra un aviso neutro de espera; el banner drástico se reserva para fallos persistentes.
- **El parser del env del agente no recortaba comentarios en línea (#883)** — agente 3.0.3.
- **La actualización fallaba sin clone git (#897)** — el SHA de main se resuelve ahora vía `git ls-remote`.

### Nuevo

- **Idioma por defecto del servidor para las notificaciones (#889)** — ajuste `alerts.lang` (Ajustes > Notificaciones, inglés por defecto), independiente del idioma de cada cliente.
- **Log de la recuperación de agentes (#890)** — todo el proceso queda registrado con prefijos `supervisor:` / `rearmer:` y documentado en `docs/AGENTE-OPENWRT.md`.
