## EN

- **Alert localization, complete** ([#712](https://github.com/gnacho/netpulse/issues/712), [#689](https://github.com/gnacho/netpulse/issues/689)): the alert feed and the web push notifications now translate from the alert type and its vars in the device language, instead of showing server-side Spanish literals.
- **Per-router high-temperature threshold** ([#716](https://github.com/gnacho/netpulse/issues/716)): each router can set its own threshold (default 65 C), used by the alert and the hot state. The global slider, which never governed the server alert, is gone.
- **Celsius or Fahrenheit** ([#717](https://github.com/gnacho/netpulse/issues/717)): a display preference applied across the UI and the in-app temperature alerts.
- **Configurable router poll interval** ([#715](https://github.com/gnacho/netpulse/issues/715)): `NETPULSE_POLL_INTERVAL` (default 30 s, previously 5 s hardcoded), and the UI refresh setting now really drives the client fallback instead of pretending to change the server poll.
- **All WireGuard interfaces** ([#713](https://github.com/gnacho/netpulse/issues/713), [#714](https://github.com/gnacho/netpulse/issues/714)): the poll discovers every `wg` interface on the router, and a single failing interface no longer takes the whole panel down.
- **Device grid density** ([#711](https://github.com/gnacho/netpulse/issues/711)): more columns on wide screens, so more devices fit per view.
- **Topology** ([#692](https://github.com/gnacho/netpulse/issues/692), [#694](https://github.com/gnacho/netpulse/issues/694)): labels no longer overlap the device icons, and quiet clients of a bridge AP stay attributed to the AP.
- **Relative times** ([#698](https://github.com/gnacho/netpulse/issues/698), [#691](https://github.com/gnacho/netpulse/issues/691)): the alerts summary shows the real relative time and the agent last-seen cell ticks every second.
- **Attach overrides to a router or port** ([#690](https://github.com/gnacho/netpulse/issues/690)): a manual override can target a router id or `routerId:port`, not only a device MAC.
- **Optional HTTPS listener** ([#696](https://github.com/gnacho/netpulse/issues/696)): `NETPULSE_TLS_ENABLED` serves HTTPS with your certificates, or a self-signed fallback, without touching the HTTP the agents use.
- **owut check** ([#695](https://github.com/gnacho/netpulse/issues/695)): detect `owut` on a router and run `owut check` for review before any upgrade.
- **Security** ([#693](https://github.com/gnacho/netpulse/issues/693)): the DHCP reservation hostname is validated and escaped before it reaches a router command.
- **Clearer agent actions** ([#718](https://github.com/gnacho/netpulse/issues/718), [#719](https://github.com/gnacho/netpulse/issues/719)): rearm shows the real reason, and token rotation no longer tells you to reinstall an agent when there is none.
- **Landing** ([#734](https://github.com/gnacho/netpulse/issues/734)): the about copy is reworked and the Ko-fi ask is replaced by asking for a GitHub star.

## ES

- **Localización de alertas, completa** ([#712](https://github.com/gnacho/netpulse/issues/712), [#689](https://github.com/gnacho/netpulse/issues/689)): el feed de alertas y las notificaciones push se traducen ahora desde el tipo de alerta y sus variables en el idioma del dispositivo, en vez de mostrar literales en español del servidor.
- **Umbral de temperatura alta por router** ([#716](https://github.com/gnacho/netpulse/issues/716)): cada router puede fijar su propio umbral (65 C por defecto), usado por la alerta y el estado caliente. El slider global, que nunca gobernaba la alerta del servidor, desaparece.
- **Celsius o Fahrenheit** ([#717](https://github.com/gnacho/netpulse/issues/717)): preferencia de presentación aplicada a toda la interfaz y a las alertas de temperatura en la app.
- **Intervalo de sondeo configurable** ([#715](https://github.com/gnacho/netpulse/issues/715)): `NETPULSE_POLL_INTERVAL` (30 s por defecto, antes 5 s fijos), y el ajuste de refresco de la interfaz ahora gobierna de verdad el respaldo del cliente en vez de aparentar cambiar el sondeo del servidor.
- **Todas las interfaces WireGuard** ([#713](https://github.com/gnacho/netpulse/issues/713), [#714](https://github.com/gnacho/netpulse/issues/714)): el sondeo descubre todas las interfaces `wg` del router, y una interfaz que falla ya no tumba el panel entero.
- **Densidad de la vista de dispositivos** ([#711](https://github.com/gnacho/netpulse/issues/711)): más columnas en pantallas anchas, para ver más dispositivos de una vez.
- **Topología** ([#692](https://github.com/gnacho/netpulse/issues/692), [#694](https://github.com/gnacho/netpulse/issues/694)): los nombres ya no se montan sobre los iconos, y los clientes callados de un AP puente se quedan atribuidos al AP.
- **Tiempos relativos** ([#698](https://github.com/gnacho/netpulse/issues/698), [#691](https://github.com/gnacho/netpulse/issues/691)): el resumen de alertas muestra el tiempo relativo real y la celda "Visto" de los agentes avanza segundo a segundo.
- **Overrides attach a router o puerto** ([#690](https://github.com/gnacho/netpulse/issues/690)): un override manual puede apuntar al id de un router o a `routerId:puerto`, no solo a la MAC de un dispositivo.
- **Listener HTTPS opcional** ([#696](https://github.com/gnacho/netpulse/issues/696)): `NETPULSE_TLS_ENABLED` sirve HTTPS con tus certificados, o con un autofirmado de reserva, sin tocar el HTTP que usan los agentes.
- **owut check** ([#695](https://github.com/gnacho/netpulse/issues/695)): detecta `owut` en un router y ejecuta `owut check` para revisión antes de cualquier actualización.
- **Seguridad** ([#693](https://github.com/gnacho/netpulse/issues/693)): el hostname de la reserva DHCP se valida y se escapa antes de llegar a un comando del router.
- **Acciones de agente más claras** ([#718](https://github.com/gnacho/netpulse/issues/718), [#719](https://github.com/gnacho/netpulse/issues/719)): el rearm muestra el motivo real y la rotación de token ya no te dice que reinstales un agente cuando no hay ninguno.
- **Landing** ([#734](https://github.com/gnacho/netpulse/issues/734)): el copy del about se reescribe y la petición de Ko-fi se sustituye por pedir una estrella en GitHub.
