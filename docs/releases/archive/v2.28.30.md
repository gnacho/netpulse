## What's new

**Alert log history survives restarts (#798)** — the alert log was memory-only, so a self-update wiped it. Alerts are now persisted to SQLite and reloaded on boot.

**Apply a device's name as a DHCP reservation (#800)** — the device edit sheet can now push the display name to the router: if the MAC already has a reservation only its hostname is updated, otherwise the reservation is created with the current IP. DNS-valid hostnames only, IP conflicts rejected, and like every router write it goes through the dry-run command plan before running.

**Editable name and type per client (#797)** — the edit sheet gains a name field and a manual type selector (persisted as overrides), fixing rename-only-icon and the type filter falling back to "Unknown" too often.

**Stable sorting and a traffic column (#799)** — the default order no longer jumps between refreshes, the desktop list has a sortable Traffic column and mobile gets a sort control.

**The update check button runs a real check (#795)** — it now triggers a fresh check instead of only reading the cached status.

**Auto-update alerts respect the UI language (#796)** — the alert now resolves from the EN/ES locales using stable result codes.

## Novedades

**El historial de alertas sobrevive a reinicios y actualizaciones (#798)** — el registro era solo memoria y un self-update lo borraba; ahora se guarda en SQLite y se recarga al arrancar.

**El nombre del dispositivo se puede aplicar como reserva DHCP (#800)** — el editor puede empujar el nombre visible al router: si la MAC ya tiene reserva se actualiza solo el hostname; si no, se crea con la IP actual. Solo hostnames DNS válidos, conflictos de IP rechazados y siempre con plan de comandos antes de ejecutar.

**Nombre y tipo editables por cliente (#797)** — el editor gana campo de nombre y selector de tipo manual (guardados como overrides).

**Orden estable y columna de tráfico (#799)** — el orden por defecto ya no baila entre refrescos, la lista de escritorio tiene columna de Tráfico y el móvil un selector de orden.

**El botón de comprobar actualizaciones hace un check real (#795)** — ahora dispara el check de verdad en vez de leer solo el estado cacheado.

**La alerta de auto-actualización respeta el idioma de la interfaz (#796)** — se resuelve desde los locales EN/ES con códigos de resultado estables.
