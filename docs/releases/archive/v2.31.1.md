## English

Patch release with the first community feedback on v2.31.0:

- Alerts that re-fire right after a server restart start unread again, instead of inheriting the read state from the previous session (#1094).
- First seen / Last seen no longer show a permanent dash; the seen marks are now written through the same device list the UI consumes (#1095).
- Roaming events from the same second keep their log order (OpenWrt logs have no milliseconds; ties break by insertion order), and the events view gains client and AP dropdowns to follow one client across the fleet (#1097).
- The client edit sheet keeps Save/Cancel next to the edited fields, and the card is titled "Edit client" (#1096).
- The unit's Open web UI and SSH copy buttons show the exact URL/command in a tooltip before you press them (#1098).
- Agent 3.0.8: a unit with no clients associated at push time no longer drops its whole wireless section (radios, scans, own BSSIDs).

## Español

Release de parche con los primeros comentarios de la comunidad sobre la v2.31.0:

- Las alertas que se re-emiten justo tras un reinicio del servidor vuelven a aparecer como no leídas, en vez de heredar el estado de la sesión anterior (#1094).
- "First seen" / "Last seen" ya no muestran un guion permanente; las marcas de visto ahora se escriben desde la misma lista de dispositivos que consume la UI (#1095).
- Los eventos de roaming del mismo segundo conservan el orden del log (los logs de OpenWrt no llevan millis; el desempate es el orden de inserción), y la vista de eventos gana desplegables de cliente y AP para seguir a un cliente entre APs (#1097).
- La tarjeta de edición de cliente mantiene Guardar/Cancelar junto a los campos que editan, y el título pasa a "Editar cliente" (#1096).
- Los botones de web y SSH copiar de la unidad muestran la URL/comando exacto en un tooltip antes de pulsar (#1098).
- Agente 3.0.8: una unidad sin clientes asociados en ese momento ya no descarta toda su sección wireless (radios, scans, BSSIDs propios).
